# Pattern Categories

Fixed list of error categories. `--pattern` in `scripts/learning_records.py` accepts only these names, so one kind of error always maps to one row in `data/weak_patterns.md`. Add a category only with `learning_records.py add-category`; do not rename or remove one that is in use. Specific details of each mistake belong in the attempt `Note`.

| Category | Description |
| --- | --- |
| time-preposition | Preposition or form of a time expression, for example `on tomorrow` instead of `tomorrow morning`. |
| preposition | Wrong, missing, or extra preposition that is not a time expression. |
| subject-verb | Subject-verb agreement, for example singular `part` with plural-form `need`. |
| tense-aspect | Tense or aspect does not fit the situation, for example `could not` instead of `haven't been able to ... yet`. |
| verb-pattern | Wrong structure after a verb, for example `help to resolve` instead of `help me resolve`. |
| article | Missing, extra, or wrong article or determiner. |
| number-fidelity | Number or quantity changed from the source, for example singular translated as plural or `all ...`. |
| word-choice | A word that is inaccurate or does not fit the meaning or register. |
| word-order | Words or clauses in an order that is unnatural or unclear. |
| collocation | Words that are correct alone but are not used together naturally. |
